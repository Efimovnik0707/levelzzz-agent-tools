# AGENTS.md

Этот репозиторий: MCP-сервер Levelzzz и плагин для AI-агентов. Плагин должен
давать агенту и skill-инструкции, и MCP-инструменты для задач, прогресса,
профиля, гильдии и истории пользователя в [Levelzzz](https://levelzzz.com)
через тот же API, которым пользуется веб-интерфейс.

## Инструменты

`list_tasks`, `complete_task`, `add_task`, `delete_task`, `update_task`,
`get_progress`, `get_profile`, `get_guild`, `get_history`.

## Когда звать инструменты

**«Сделал X» / «отметь X»**: вызвать `list_tasks`, сматчить фразу
пользователя с задачей по смыслу. Ровно один кандидат: `complete_task`. Ноль
или больше одного: не гадать, спросить, какую именно задачу отметить.
Никогда не отмечать задачу выполненной без явного утверждения пользователя,
что она сделана.

**«Добавь задачу»**: `add_task`. Пресет: `preset_id`. Своя задача: `title` +
`tier` (I — быстрая 10-20 мин, II — основная 45-90 мин, III — ключевое
усилие дня) + `schedule_type`/`schedule_count`.

**«Удали задачу»**: сматчить через `list_tasks`, затем `delete_task`. Если
по задаче уже есть выполнение на этой неделе, сервер вернёт 409. В этом
случае предложить `update_task` (замену) вместо удаления.

**«Замени/отредактируй задачу»**: `update_task`. Первая замена задачи на
неделе бесплатна, дальше платно и лимитировано.

**Прогресс/профиль/гильдия/история**: `get_progress`, `get_profile`,
`get_guild`, `get_history` соответственно. Пересказывать результат своими
словами, коротко, с конкретными цифрами.

## Настройка

Обязательна переменная окружения `LEVELZZZ_API_KEY` (ключ из профиля
Levelzzz: Профиль → Агентский доступ → Создать). `LEVELZZZ_API_URL` нужна
только для self-host или локальной разработки, по умолчанию сервер ходит на
прод.

## Установка для Codex/ChatGPT

Когда пользователь просит подключить Levelzzz в Codex/ChatGPT:

1. Для публичного плагина использовать каталог плагинов ChatGPT/Codex и OAuth
   Levelzzz. В этом сценарии не просить API-ключ и не показывать его в чате.
   Пока публичная версия не опубликована, использовать repo marketplace из
   `.agents/plugins/marketplace.json`; bundle лежит в `plugin/` и подключает
   remote MCP через `plugin/.app.json`.
2. Не писать пользователю Claude Code slash-команды `/plugin marketplace add`
   и `/plugin install`: в Codex Desktop такого chat-командного флоу может не
   быть. Маркетплейс добавляется через Codex CLI, а сам плагин устанавливается
   через UI ChatGPT/Codex.
3. Только как fallback для локального stdio MCP попросить пользователя создать
   ключ в Levelzzz: Профиль → Агентский доступ → Создать, затем настроить сервер:
   `codex mcp add levelzzz --env LEVELZZZ_API_KEY=<asc_...> -- npx -y @levelzzz/mcp`.
4. Проверить подключение через `get_profile`; в ответе должны быть handle,
   уровень, ранг, стрик и кристаллы.

Если после установки плагина Codex отвечает «Ключ Levelzzz недействителен или
отозван», проверить, что в env не попала буквальная строка
`${user_config.api_key}` или `YOUR_KEY`. Для Codex Desktop надежный вариант —
прямой MCP `levelzzz` с явным `LEVELZZZ_API_KEY`.

Подробности по каждому сценарию: `plugin/skills/levelzzz-tracker/SKILL.md`.
