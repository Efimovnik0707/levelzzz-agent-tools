# Ascend agent-tools

MCP-инструменты для агентов (Claude Code и любых других MCP-клиентов): агент
сам отмечает твои задачи в Ascend, добавляет новые и показывает прогресс —
через тот же API, которым пользуется веб-интерфейс.

## Что внутри

- `mcp/` — stdio MCP-сервер `ascend-mcp` (один файл, `@modelcontextprotocol/sdk`).
  Инструменты: `list_tasks`, `complete_task`, `add_task`, `get_progress`.
- `plugin/` — плагин Claude Code (marketplace + MCP-конфиг + skill с триггерами).

## Безопасность ключа

API-ключ Ascend (`asc_...`) даёт доступ к твоему аккаунту наравне с логином:
им можно отмечать задачи, добавлять их и читать прогресс. Он не даёт доступа
ни к чему за пределами Ascend.

- Создаётся в **Профиле → Агентский доступ → Создать**. Полный ключ
  показывается **один раз**, дальше виден только префикс.
- Отозвать можно там же в любой момент — старый ключ сразу перестаёт
  работать.
- Не коммить ключ в git, не вставляй в публичные чаты. Если ключ утёк —
  просто отзови его в профиле и создай новый.

## Установка

### Путь 1: Claude Code (плагин)

```
/plugin marketplace add Efimovnik0707/ascend-agent-tools
/plugin install ascend
```

При установке Claude Code спросит переменные окружения `ASCEND_API_URL` и
`ASCEND_API_KEY` — укажи URL сервера Ascend и ключ из профиля.

### Путь 2: любой MCP-клиент

Добавь сервер вручную (пример для `.mcp.json` / конфига клиента):

```json
{
  "mcpServers": {
    "ascend": {
      "command": "npx",
      "args": ["-y", "github:Efimovnik0707/ascend-agent-tools"],
      "env": {
        "ASCEND_API_URL": "https://<твой-ascend-url>",
        "ASCEND_API_KEY": "asc_..."
      }
    }
  }
}
```

## FAQ

**Это читерство?** Нет. Агент делает ровно то же, что твой клик в
интерфейсе — тот же API, те же формулы, те же лимиты дня.

**Какие лимиты?** Те же, что и в UI: те же потолки XP/урона в день, тот же
дедуп задач, тот же лимит на 7 задач в контракте.

**Ключ утёк, что делать?** Отзови его в Профиле → Агентский доступ и создай
новый. Отозванный ключ перестаёт работать сразу.
